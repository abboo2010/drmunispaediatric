# Gallery photo folders

Each service has a folder, and each condition/procedure has its own sub-folder inside it:

    img/gallery/<service>/<item>/1.jpg
    img/gallery/<service>/<item>/2.jpg
    img/gallery/<service>/<item>/3.jpg   ... up to 24 photos per item

Rules
- Name photos 1.jpg, 2.jpg, 3.jpg ... with no gaps (the gallery stops at the first missing number).
- Use .jpg files, about 1600 px on the long side and under 400 KB each.
- Optional caption: add a file called captions.json next to the photos, e.g. {"1": "Day 1 after surgery"}.
- Nothing else needs editing. Upload the photos, commit, and the gallery page shows them.
- Only use photos with the written consent of the child's parent/guardian, with no names, faces or identifying marks visible unless consent covers it.
